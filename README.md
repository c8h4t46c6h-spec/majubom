# 마주봄 웹앱 (리디자인)

발달장애 자녀를 둔 부모를 위한 마주봄 교육 프로그램의 학습·커뮤니티·기록 앱입니다.
빌드 과정 없이 HTML/CSS/JS만으로 동작하므로 Vercel에 그대로 올리면 됩니다.
(기존 Flutter 앱의 로고·마스코트·감정 이미지를 그대로 사용했습니다.)

## 파일 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 진입 페이지 (폰트·스크립트 불러오기) |
| `styles.css` | 전체 디자인 (색상 변수는 맨 위 `:root`에 모여 있음) |
| `js/data.js` | **콘텐츠 전부**: 차시, 퀴즈, 사전 검사 문항, 정서 지원 콘텐츠, 숏폼, 등급·보상, 이용규칙, 개인정보 동의서 |
| `js/app.js` | 화면과 기능 코드 (화면 = `vHome`, `vLearn` 같은 `v...` 함수, 버튼 동작 = `A` 객체, 폼 제출 = `F` 객체) |
| `assets/images/` | 기존 앱에서 가져온 이미지 |
| `vercel.json`, `manifest.json` | 배포 설정, 홈 화면 추가용 정보 |

## 기능 (기획서 ‘나. 애플리케이션 기능’ ①~⑩ 기준)
| 구분 | 기능 |
|---|---|
| 학습 | ① 사전 검사(초기 감정 상태 · 장애 수용 단계 · 애착 유형 <표15·16>) ② 온라인 강의(3차시 플립러닝) ③ 차시별 퀴즈(3·4차시, O/X·객관식·단답형) ⑤ 정서 지원 콘텐츠 + 알림 ⑥ 숏폼(카드뉴스 · 발달 유형별 이해 · 유튜브 링크) |
| 커뮤니티 | ④ 부모 커뮤니티(글·댓글·공감, [필독] 이용규칙 공지) ⑦ 전문가 게시판(분야·연령·상황·질문, 하루 질문 횟수 제한, 전문가 답변) ⑩ 등급제(씨앗 → 새싹 → 꽃) |
| 기록 | ⑧ 육아 체크리스트(최대 3개, 최근 4주) ⑨ 감정 기록(이모티콘·메모·음성→텍스트·전문가 공유) |
| 마이 | 내 정보 수정, 개인정보 수집·이용 동의(필수/선택), 회원 탈퇴, 알림 설정 |

- 등급 보상: 씨앗 = 기본 / 새싹(댓글 5개) = 전문가 질문 하루 1회 추가 / 꽃(댓글 15개) = 선배 부모 활동 신청
- 4주 실천 리포트: 기획서 3단계 행동 평가 <표24> 애플리케이션 기반 실천 데이터(p.58)를 부모가 볼 수 있게 모은 화면 (기획서에 따로 이름 붙은 기능은 아님)
- 체험 계정: 로그인 화면의 **부모님으로 / 전문가로** 버튼 (또는 `demo` / `expert`, 비밀번호 `1234`)

## 주의 (시연용 데이터 저장)
지금은 데이터가 **각자의 브라우저(localStorage)** 에만 저장됩니다. 그래서
- 다른 기기·다른 사용자와 글/댓글/질문이 공유되지 않습니다.
- 실제 운영하려면 Firebase(Firestore + Auth)나 Supabase 같은 서버 DB 연결이 필요합니다. `js/app.js`의 store 부분(`load`, `save`, `db`)을 교체하면 됩니다.
- 비밀번호도 브라우저에만 저장되는 시연용 방식이라, 실제 운영 시에는 Firebase Auth 등으로 바꿔야 합니다.
- 푸시 알림은 앱을 열 때 브라우저 알림으로 보여주는 방식입니다. 앱을 닫아도 오는 진짜 푸시는 서버가 필요합니다.
- 체험 데이터를 처음 상태로 되돌리려면 마이 → 맨 아래 ‘체험 데이터 초기화’.

## 로컬에서 보기
```bash
python3 -m http.server 5173
```
이 폴더에서 실행한 뒤 브라우저에서 http://localhost:5173 열기. (`index.html`을 더블클릭해도 대부분 동작하지만, 로그인 암호화 기능 때문에 서버로 여는 걸 권장합니다.)

## Vercel 배포
### 방법 A — GitHub 연동 (추천)
1. github.com에서 새 저장소를 만들고 이 폴더의 파일을 모두 업로드 (웹에서 드래그 앤 드롭 가능)
2. vercel.com 로그인 → **Add New… → Project** → 방금 만든 저장소 **Import**
3. Framework Preset: **Other**, Build Command·Output Directory는 비워 두고 **Deploy**
4. 이후 GitHub에 파일을 올릴 때마다 자동으로 재배포됩니다.

### 방법 B — Vercel CLI (Node가 있는 컴퓨터에서)
```bash
npx vercel --prod
```
